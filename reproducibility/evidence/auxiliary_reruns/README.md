## Files and verification

- `web_pilot_results.json`, `xling_results.json`: current outcomes.
- `*_predictions*.csv`: fixed input pairs, scores and removal decisions.
- `*_features*.csv`: feature matrices for manual or numerical inspection.
- `scores.npz`: exact binary score arrays, avoiding CSV parser rounding.
- `frozen_models.npz` / `.json`: numerical MLP and logistic weights, scalers,
  feature order and fixed estimator settings; no pickle is required to
  inspect or verify inference.
- `primary_mcq_calibration.json`: every primary MCQ calibration row's label
  and score, clean-group maxima and pilot cutoff.
- `xling_split_manifest.csv`: all fixed cross-lingual row/group partitions.
- `run_manifest.json`: input/source hashes, environment and primary cache
  identity. The trusted local cache is an execution optimization only and
  is not a distributed artifact.
- `verification.json`: independent manual MLP/logistic inference,
  threshold recomputation, binary-score comparison and subgroup-count
  checks. All passed.
- `standalone_verification.json`: the portable driver was executed again
  without the private primary-state cache. It regenerated byte-identical
  result JSON, prediction CSVs, frozen weights, binary scores and MCQ
  calibration inputs.

The original `run_r2_wild.py` construction was also executed up to its model
loading step against the supplied report inputs. All 238 paired rows match
the archived CSV in each of the 11 fields used for construction/evaluation;
see the accompanying `pilot_construction_verification.json`.

## Portable reproduction

Use Python 3.12, NumPy 1.26.4, SciPy 1.13.1, scikit-learn 1.5.2,
pandas 2.2.2 and joblib. Put `pairs_arith_v2.csv`, `pairs_mcq_v2.csv`,
`pairs_math_v2.csv`, `r2_wild_pairs.csv`, and `pairs_xling.csv` in the input
directory; point `--source-dir` to the unchanged historical implementation.

Run the commands in [Auxiliary probe refit](../../README.md#auxiliary-probe-refit)
from the package's `reproducibility/` directory (or `experiment_source/` in the
complete ZIP). The commands use the bundled CSVs and historical implementation,
write to a fresh run directory, and verify the resulting numerical evidence.

The output directory must be empty. The driver rebuilds the same primary
model if `--primary-state` is omitted; it never overwrites the input CSVs or
historical scripts. The historical pilot removal columns are discarded
before fresh inference. This experiment retains the historical exploratory
constructed-data threshold procedure; it is separate from the protocol-valid
raw-search audit and its clean-only tolerance guarantee.

## Recorded verification deviation

The first verifier used pandas' default CSV float parser. That parser rounded
one calibration score at the selected cutoff, producing one disagreement in
a saved calibration decision. Round-trip float parsing resolved the artifact
without changing any model or result. Binary `scores.npz` was added, and a
fresh export run produced byte-identical result JSON, prediction CSV and
model-weight files. The original run and failed-verifier record remain in
the local trace directory; they are not rewritten as successful history.
